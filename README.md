# OCI-to-Drata Custom Connection

Read-only Oracle Cloud Infrastructure configuration-evidence collector that
normalizes findings into one schema-valid JSON record and upserts it into an
existing Drata Custom Connection.

Full setup, least-privilege policy, execution, validation, and
troubleshooting docs land here as the build completes. See
[oci_to_drata_mvp_build_spec.md](oci_to_drata_mvp_build_spec.md) for the
authoritative build specification and
[TRACEABILITY.md](TRACEABILITY.md) for the requirement/API traceability
matrix.

**Status: work in progress.** Do not deploy to a production tenancy yet.
